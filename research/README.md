Входы всех направлений: [handout](../hack-context/hackathon-students/docs/handout.md), [вопросы](../hack-context/hackathon-students/docs/tasks.md), [профилирование коллег](../docs/profiling.md), базовый SHA выше. Содержание чужого profiling не становится независимо доказанным от добавления ссылки.

Для каждого публикуемого результата нужны: intent, owner, input/source URL и SHA/ref/date, метод, evidence locator, фактический результат, ограничения, coverage/gaps и следующий check. Статусы: unverified / validated (конкретный claim) / unresolved / rejected / stale. Отклонённые идеи сохраняются с причиной. Совпадение контрольных сумм не доказывает отсутствие потерь, fanout и неверного знаменателя.

Связанные места: [идеи](../docs/ideas.md), [работы и владельцы](../docs/workstreams.md), [правила кандидата](../AGENTS.md). Журнал решений и explainer публикуются отдельно. Локальные истории инструментов, личные настройки, secrets и полные runtime dumps в общий индекс не входят.
