## Правила, выборы и неизвестное

| Класс | Как читать в материалах | Пример |
|---|---|---|
| Правило пользователя / задания | Обязательная граница | raw неизменен; ответы из модели; неизвестное ≠ 0; весь объём сдачи |
| Рабочий выбор агента | Обратимая реализация, без приписанного approval | Detail constellation, натуральные ключи, пары review-order, numeric без раннего округления |
| Не решено | Именованные варианты сохраняются | Counts Q1/Q2, окна, веса отзывов, day/timestamp late, область дашборда |
| Проверено | Всегда указан метод и артефакт | Прочитан DDL; CSV-пример; static check; отдельно будущий DB run |
