## Роли и незавершённые задачи

Sol ведёт оркестрацию, реализацию и второе мнение. Terra получает ограниченные
быстрые задачи. Astra используется для сложных неоднозначностей, которые Sol не
закрыл, и точечного независимого мнения. После уточнения лимитов два перекрывающихся
Astra-разбора доставки и отзывов получили запрос отмены. Пользователь затем уточнил, что уже работающих агентов следовало оставить; новых отмен и замен нет. Их возможные частичные
файлы не считаются завершённым вкладом. У Astra оставлена архитектура истории
категорий; доставку исследует Sol, данные оценок и платежей/цен — Terra.

Прежние три задачи принадлежали старому треду; их полные финальные сообщения
прочитаны координатором. Управление их процессами не переносилось. Нынешние задачи
созданы в новом треде и имеют непересекающиеся области. Нет рутинных рассылок,
polling или новой панели согласования.

## Исправления и проверка

1. Семь новых mart-представлений добавлены в явный список удаления объектов
   перед rebuild. Без этого PostgreSQL RESTRICT блокировал бы повторную сборку.
2. По независимому [review Astra](evidence/astra-q6-q10-review.md) усилена fixture:
   средние, числовые доли, отдельные знаменатели Q10, повтор одной оценки,
   границы 1/2/3 заказов при тестовом пороге 2, отсутствие даты на границе.
3. На установленном PostgreSQL **16.15** выполнены поведенческие Q6–Q10 на
   **16 синтетических заказах**. Отдельно на исходных **10 синтетических заказах**:
   настоящий wrapper `build`, rebuild, сравнение содержимого/DDL, преднамеренная
   поздняя ошибка с rollback, неизменность raw, `answers` и `check`.
   [Протокол с хешами](evidence/pg16-small-02/summary.json).
4. Две заведомо неверные модификации — `> порог` и доля опозданий со знаменателем
   всех заказов — обнаружены усиленным тестом на PG16. Оба временных сервера
   остановлены; [результаты](evidence/mutation-results.json).
5. Первый малый запуск сохранил отказ до fixture: initdb без явного UTF8 дал
   SQL_ASCII, psycopg возвращал имя базы как bytes. Исправлен только runner,
   добавлено `--encoding=UTF8`; [неуспешный запуск](evidence/pg16-small-01/summary.json)
   сохранён. Это не свидетельство ошибочного бизнес-SQL.

Воспроизводимый runner: `python3 docs/phase-20261028/verify-small-pg16.py CHECKOUT NEW_EVIDENCE_DIR`.

Unix socket, `shared_buffers=16MB` и не загружает CSV Olist. Копия фактически
