## Вброс

1. **Продавец меняет категорию товара, прошлые отчёты не должны меняться.**
   Сейчас у товара одна категория (`dim_product → dim_category`), история не хранится.
   Нужно SCD2: `product_id, category_key, valid_from, valid_to, is_current`.
   Отчёты по категориям соединять по дате заказа:
   `order_purchase_timestamp >= valid_from AND (valid_to IS NULL OR < valid_to)`.
   В исходных данных изменений нет, поэтому первая версия каждой строки — `valid_from` = начало
   истории. Для защиты стоит показать тест: сменили категорию одному товару → Q5 за прошлое не изменился.
2. **Покупатели переезжают, в заказе нужен адрес на момент заказа.**
   Уже сделано: адрес (`customer_zip_code_prefix`, `customer_city`, `customer_state`) лежит
   на `fact_order` / `dim_customer_context`, а не на `dim_customer`. Нужно только описать
   в записке и, может быть, добавить проверку «адрес берётся с заказа».
