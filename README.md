# Capibara: модель данных Olist

[Комплект для команды и жюри](docs/submission/index.html) · [Передача и порядок демо](docs/submission/FINAL-HANDOFF.md)

Решение кейса RWB использует восемь CSV Olist. `raw` сохраняется; ответы строятся из `core` и `mart`. Реализованы сборка, SQL и определения для всех десяти опубликованных вопросов, а также история категорий. Состав сдачи и границы проверок собраны в единой точке входа выше.

Полный запуск текущей модели на Olist и результаты Q6–Q10 из неё ещё не выполнены. На малых синтетических данных PostgreSQL 16.15 прошли 182 проверки с привязкой к хешам кода: [протокол](docs/phase-20261028/evidence/release-pg16/summary.json). Ранее опубликованная [полная выгрузка Q1–Q5](research/implementation-review-20261028/full-model-answers.json) относится к другой версии модели; это не подтверждение текущего полного lifecycle.

Для автономного показа доступны [полный дашборд предыдущей выгрузки](dashboard/index.html) с соседним `data.js` и [отдельный HTML на 1 000 реальных заказов](dashboard/olist.html). Происхождение и ограничения — в [передаче](docs/submission/FINAL-HANDOFF.md).
