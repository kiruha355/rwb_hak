# Capibara — дашборд и обозреватель модели

Веб-приложение поверх нашей модели: API читает `core` и `mart` вживую (только чтение),
фронтенд показывает дашборд и логику модели в стиле презентации.

## Что внутри

| Раздел | Что показывает | Откуда данные |
|---|---|---|
| Обзор | выручка, заказы, чек, покупатели, опоздания, срок доставки, оценка; графики по месяцам | `mart.v_orders`, `mart.v_order_items`, `mart.v_order_delivery_variants`, календарь `core.dim_date` |
| Цена опоздания | оценка вовремя / с опозданием, этап задержки, сроки, штаты | `mart.v_orders` + `mart.v_order_delivery_variants` |
| Коммерция | категории, топ-10 продавцов, способы оплаты | `mart.v_order_items`, `core.fact_payment` |
| Как устроена модель | raw → core → mart по клику, SQL витрин, сквозной путь заказа | каталог базы (`pg_catalog`), `raw`, `core`, `mart` |
| Проверки и качество | 201 самопроверка, баланс raw ↔ core, журнал аномалий | `core.check_results`, `core.data_issues` |
| Ответы Q1–Q5 | ответы и сравнение с контрольными цифрами задания | `mart.q01…q05` |
| Паспорта метрик | формула, уровень, окно, что складывается | `mart.metric_definitions` |

Фильтры (период, штат, категория) общие для первых трёх разделов и хранятся в адресе страницы.

## Запуск

Нужна собранная модель (`make build`) в локальной базе `marketplace`.

```bash
cd app/api && npm install && npm start      # API на http://127.0.0.1:8787
cd app/web && npm install && npm run dev    # фронт на http://localhost:5173
```

Строка подключения по умолчанию — `postgresql://hack:hack@127.0.0.1:5432/marketplace`,
можно задать `DATABASE_URL`. Соединение открывается только на чтение, запросы ограничены 20 секундами.
